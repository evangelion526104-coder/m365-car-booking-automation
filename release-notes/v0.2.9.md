# v0.2.9 - ATA-9627 V3 測試實作版

日期：2026-07-15

## 版本目的

本版本將 ATA-9627 公務車 Resource Calendar 的 V3 事件讀取測試，整理成可直接於 Power Automate 畫面建立與執行的實作版。

本版本尚未宣告 V3 讀取成功；需待 Power Automate 實際執行後，確認是否可取得事件資料、Event ID 與 iCalUId。

## 新增內容

- 新增 `power-automate/ata9627-v3-test-implementation.md`。
- 明確定義 `公務車功能測試-ATA9627事件讀取` 的動作順序。
- 明確指定 ATA-9627 Calendar ID：`6049e1d1-b34c-4cca-b530-2c7c4b77abe9`。
- 新增事件數量、TEST 事件數量、第一筆事件原始資料與欄位摘要的測試輸出設計。
- 新增 V3 成功、部分成功與失敗時的判斷方式。
- 新增成功後的下一步 MVP 草案：`公務車行事曆同步至 SharePoint - ATA9627 MVP`。

## 下一步

1. 在 Power Automate 建立或調整 `公務車功能測試-ATA9627事件讀取`。
2. 使用 `Get_ATA9627_Events_V3` 讀取 ATA-9627 未來 7 天事件。
3. 回填 `Compose_All_Event_Count`、`Compose_TEST_Event_Count` 與 `Compose_First_Event_Raw`。
4. 若可取得 Event ID 或 iCalUId，進入 ATA-9627 SharePoint 同步 MVP。

## 上線限制

在 V3 實測成功前，不得啟用正式 SharePoint 同步，也不得啟用 Teams Adaptive Card 自動通知。
